# Empire Fades - Premium Luxury Barbershop

A premium, luxury one-page website for Empire Fades, Liverpool's elite barbershop. Built with React 19, Tailwind CSS 4, and Vite, this site is optimized for performance, accessibility, and high-end visual appeal.

## Features

1. **Luxury Hero Carousel** - High-impact visual introduction to the brand.
2. **The Empire Standard** - About section detailing the craftsmanship and mastery.
3. **Premium Services** - Showcase of elite grooming services and pricing.
4. **The Lookbook** - Visual gallery of precision cuts and fades.
5. **Mastery in Detail** - Call to action for walk-ins and inquiries.
6. **Visit Us** - Integrated Google Maps and detailed business information.

## Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS 4, Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite 7
- **Deployment**: Optimized for Vercel

## Business Details

- **Name**: Empire Fades
- **Location**: Shop 219/263 Elizabeth St, Liverpool NSW 2170, Australia
- **Focus**: Precision fades, classic cuts, premium beard styling

## Deployment

This project is production-ready for Vercel.

```bash
npm install
npm run build
npm run start
```
